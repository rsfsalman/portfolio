# Personal Portfolio Website

This repository contains my personal software development portfolio website, created as part of a college assignment at **Mohawk College**.

The website presents an overview of my skills, academic background, and selected projects developed during my studies in Software Development.

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- Git & GitHub Pages

## Website Sections

The portfolio includes the following sections:

- **Home / Summary** – Brief introduction and summary
- **Skills** – Programming languages, web technologies, tools, and workflows
- **Projects** – Selected academic and personal projects, including:
    - Python RESTful API web application (CRUD)
    - Python-based dynamic HTML generation project
    - SVG-based interactive game
- **Resume** – Education, skills, and academic experience (PDF included)
- **Contact Information** – Email, GitHub profile, and portfolio links
